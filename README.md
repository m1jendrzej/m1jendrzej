## Current project — Legiocopter

**Legiocopter** is a custom quadcopter project built around the **ESP32-C6**.

I'm using it mainly as a playground for embedded software, electronics and flight-control ideas.

```text id="l3rw8k"
ESP32-C6
   │
   ├── I²C ───── LSM6DSO IMU
   ├── ADC ───── Battery monitoring
   ├── PWM ───── Motor control
   └── Wi-Fi ─── Remote controller
```

### What I'm working on

* custom C++ libraries for hardware modules
* IMU communication and sensor processing
* motor control
* battery monitoring
* wireless communication
* FreeRTOS integration
* flight-control algorithms

The next steps are **sensor fusion, attitude estimation and PID-based stabilization**.
